# UI 디자인 가이드

## 디자인 원칙
1. 장난감처럼 보여야 한다. 밝고 단단한 색, 크고 두꺼운 형태. 대시보드나 마케팅 페이지가 아니다.
2. 1~3m 떨어진 칠판 앞에서 읽히고 눌려야 한다. 글자와 버튼은 데스크톱 기준보다 훨씬 크게.
3. 아이 손이 닿는 곳에서 조작한다. 조작 요소는 화면 아래쪽, 보기 전용 정보는 위쪽.
4. 약한 칠판에서도 부드러워야 한다. 그림자·필터·큰 이미지 없이 단색 면과 선으로 그린다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 (게다가 칠판에서 느림) |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

## 크기
- 루트 글자 크기는 화면 짧은 변에 비례(`vmin` 기반)시켜 칠판·PC 어디서든 비율 유지.
- 최소 터치 대상: 56 CSS px 이상, 주요 버튼은 72 CSS px 이상.
- 퍼즐 칸 크기: 칸 너비·높이에서 계산하되 조각과 판은 항상 같은 칸 크기.

## 컴포넌트
### 버튼 (나무 블록)
그림자 대신 **두꺼운 아래 테두리**로 두께를 낸다 (`box-shadow` 금지).
```
보통 (.btn):            면 --panel, 테두리 3px --ink, 아래 테두리 0.4rem, 모서리 14px, 굵게
주요 (.btn-primary):    면 --accent, 글자 --on-accent
선택됨 (aria-pressed):  면 --pressed, 눌린 모양으로 고정
못 누름 (:disabled):    투명도 0.4
```
눌린 모양: 아래 테두리를 0.15rem으로 줄이고 그만큼(0.25rem) `margin-top`을 늘린다 → 바닥은 제자리, 면만 내려간다.
`transform`이 아니라 여백으로 하는 이유: 줄 맞춤(align-items)이 흔들리지 않고 옆 버튼이 밀리지 않는다.
메뉴 게임 카드·라운드 결과 막대도 같은 모양(테두리 4px, 아래 0.5rem). 최종 결과 줄은 누르는 요소가 아니므로 테두리 3px, 아래 0.35rem, 왼쪽은 플레이어색 1rem.
판 안의 돌리기·뒤집기(SVG)는 면 아래에 `--ink` 두께 블록(칸 너비의 0.24)을 깐다.
hover 효과에 의존하지 않는다(터치 기기).

### 플레이어 칸
```
머리: 플레이어색 띠(0.8rem) + 색 블록 + 이름 + 난이도 / 점수 (큰 글씨) / 상태
몸통: 크림 면, 모서리 0 (칸끼리 딱 붙어 4px --ink 경계선으로 구분)
```

### 메뉴
제목 위에 플레이어 4색 블록 장식. 게임 카드 오른쪽에 그 게임의 작은 그림(`GameModule.Icon`, 블록 퍼즐은 실제 조각 셋).

## 레이아웃
- 플레이어 칸은 가로로 나란히 1~4개. 2×2 금지.
- 각 칸: 위쪽 1/3 = 머리·상태, 아래쪽 2/3 = 퍼즐판 + 트레이.
- 메뉴·설정 화면도 주요 버튼은 화면 아래쪽 절반에 둔다.
- 칠판 IR 터치는 화면 맨 아래 가장자리에서 둔하다. 누르는 요소는 화면 밖으로 잘리거나 아래 가장자리에 붙지 않게 아래 여백을 1.5rem 이상 둔다. 칠판 화면(1280×720)에서 최대 인원일 때도 스크롤 없이 들어가야 한다.
- 간격은 margin/padding이나 flexbox `gap`(칠판 Chrome 99 지원)으로 낸다.

## 애니메이션
- 조각 자리 맞춤: transform 120ms ease-out
- 회전: 120ms
- 정답: 칸 전체 짧은 확대·축소(300ms) + "완성!" 표시
- 카운트다운 숫자: 등장 200ms
- 그 외 애니메이션 금지. `transform`·`opacity`만 애니메이트한다.

## 아이콘
- 인라인 SVG, 굵은 선(strokeWidth 3 이상)
- 아이콘만 있는 버튼 금지 — 반드시 한글 라벨을 함께 ("돌리기", "뒤집기", "전체화면")

## 쌓기 퍼즐 (2탄, ADR-008)
블록 퍼즐과 다른 점만 적는다. 나머지는 위 규칙을 그대로 따른다.
- **크기**: 트레이의 조각과 판 밖에 둔 조각은 판의 0.6배로 그린다. 집어 올리면 1배(판과 같은 크기)다. 위의 "조각과 판은 같은 칸 크기"의 의도적 예외다.
- **회전 애니메이션**: 눕히기·돌리기는 새 방향을 바로 적용하고 화면에서만 220ms 동안 되돌아오며 굴러간다. 정육면체 꼭짓점을 매 프레임 다시 투영하므로 "transform·opacity만 애니메이트"의 예외다. 판 돌리기도 매 프레임 다시 그린다.
- **정육면체 음영**: 보이는 면만 그린다. 면 색 위에 `--ink`를 반투명으로 덮어 어둡게 한다. 덮는 진하기(투명도) = (1 − n.z) × (0.24 + 0.14 × (n·r)). n은 면의 법선, r은 화면 오른쪽 방향이다. 그라데이션·그림자·필터 없이 단색 면과 `--ink` 테두리만 쓴다.
- **빈칸·미리보기·흐림**:
  - 아직 안 채운 목표 칸: `--target` 반투명 점선 정육면체
  - 놓일 자리 미리보기: 진한 모습(붙은 모습)
  - 판에 걸쳤지만 못 놓는 끌기: 투명도 0.5
  - 떨어질 자리를 가리는 판 위 정육면체: 투명도 0.25
- **판 바닥**: 바닥 모양 칸은 `--target`, 바운딩박스의 나머지 칸은 `--margin-cell`, 격자는 `--grid-line`. 실루엣은 굵게, 풀면 `--ok`.
- **조각 색**: 블록 퍼즐의 같은 id 색을 쓰고, 새 조각은 Y4 ← P5 `#8A5A3B`, R4 ← L5 `#8DBB2E`, Q4 ← U5 `#22507C`를 빌린다.
- **버튼**: "돌리기"·"눕히기"(쉬움에서는 눕히기 숨김). 블록 퍼즐 판 버튼과 같은 나무 블록 모양이고 56 CSS px 이상이며 `pointerdown`에 반응한다.

## 과일 종치기 (3탄, ADR-009)
블록 퍼즐과 다른 점만 적는다.
- **과일 색** (1탄 조각 색): 딸기 ← I3 `#D9442E` · 바나나 ← L3 `#F2B53A` · 라임 ← L5 `#8DBB2E` · 블루베리 ← U5 `#22507C` · 잎·꼭지 ← T4 `#2E9E55`
- **카드**: 크림(`--panel`) 면, `--ink` 굵은 테두리, 과일 1~5개를 주사위 눈처럼. 빈 자리는 `--off-edge` 점선.
- **뒤집기 버튼**: 차례면 `--accent`, 아니면 `--off` 면·`--off-edge` 테두리.
- **종**: `--pressed` 면 + `--ink` 테두리 + 아래 두께, 라벨 "종".
- **결과 글자**: 맞음 `--ok`, 틀림 `--warn`.
- **애니메이션 예외**: 새 카드 등장 180ms(scale 0.85→1 + opacity), 카드를 가져간 사람의 장수 300ms 확대·축소. `transform`·`opacity`만 쓴다.

# PRD: 우리집 보드게임

## 목표
Play Store가 없는 오래된 LG 전자칠판에서, 설치 없이 브라우저 주소만 열어 아이들과 함께 보드게임을 즐긴다. 게임은 하나씩 계속 늘려간다.

## 사용자
- 칠판 앞에 선 1~4명의 가족 (나이 차가 큰 아이들 + 부모)
- 부모가 게임을 고르고 설정하고, 아이들은 터치로 플레이

## 핵심 기능 (MVP: 블록 퍼즐)
1. 우봉고 스타일 블록 퍼즐: 주어진 조각을 끌고·돌리고·뒤집어 목표 모양을 빈틈없이 채운다. 퍼즐은 항상 풀리도록 자동 생성
2. 1~4인 동시 플레이: 화면을 가로로 나란히 나눠 각자 자기 칸에서 동시에 퍼즐을 푼다. 1인은 타임어택(최고기록 저장)
3. 플레이어별 난이도(쉬움/보통/어려움) + 라운드제 점수(순위 1등 3점·2등 2점·해결 1점 + 빠르기 보너스 +2/+1, 기본 5라운드). 시간은 라운드마다(60/90/120초) 또는 판 전체 타임어택(모두가 시계 하나, 기본 300초) 중 고른다. 최종 결과에 총 걸린 시간을 보여주고, 총점이 같으면 총 시간이 짧은 쪽이 앞선다
4. 공통 셸: 게임 메뉴, 플레이어 설정, 라운드·타이머·점수판, 결과 화면 — 다음 게임이 재사용
5. 기기 진단 페이지(`check.html`): 칠판 브라우저 버전·화면·동시 터치 수 확인
6. 2탄 "쌓기 퍼즐"(3D): 정육면체 조각을 쌓아 목표 모양을 정확히 2층까지 채운다. 판을 손으로 돌려 가려진 1층을 본다. 같은 셸을 쓰되 라운드 제한시간은 게임별로 쌓기 퍼즐 90/120/150초(기본 120초), 1인 최고기록도 게임별로 저장한다. 설계: `docs/superpowers/specs/2026-10-24-stack-puzzle-design.md`, 계획: `docs/superpowers/plans/2026-10-24-stack-puzzle.md`, 결정: ADR-008
7. 3탄 "과일 종치기"(2~4인): 원작 규칙대로 카드를 뒤집다가 같은 과일이 딱 5개 보이면 자기 칸의 종을 친다(칸마다 종). 설계: `docs/superpowers/specs/2026-10-25-fruit-bell-design.md`, 계획: `docs/superpowers/plans/2026-10-25-fruit-bell.md`, 결정: ADR-009

## MVP 제외 사항
- 폰·태블릿을 컨트롤러로 쓰는 온라인 대전, 서버, 계정
- 원작 카드·그림·이름 (3D는 2탄 쌓기 퍼즐로 진행: `docs/superpowers/plans/2026-10-24-stack-puzzle.md`)
- 힌트, 튜토리얼 애니메이션, 배경음악
